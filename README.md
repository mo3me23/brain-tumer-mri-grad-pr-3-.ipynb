# brain-tumer-mri-grad-pr-3-.ipynb

🧠 Brain Tumor MRI Classification
📌 About The Project
An AI-based Computer Vision project designed to detect and classify brain tumors from MRI scans.

The pipeline pre-processes MRI images by automatically cropping the brain contour—removing unnecessary backgrounds and noise—and then classifies the images accurately using deep learning techniques.

🛠️ Tech Stack
Language: Python

Deep Learning: TensorFlow / Keras (EfficientNetB0)

Computer Vision: OpenCV (Contour detection & image cropping)

Data Processing: NumPy, Pandas

Visualization: Matplotlib, Seaborn

🚀 Key Features
Adaptive Preprocessing: Automated brain contour cropping to eliminate background noise and focus strictly on the ROI (Region of Interest).

Data Augmentation: Enhanced dataset variability to improve generalization and prevent overfitting.

Transfer Learning: Leverages EfficientNetB0 architecture to achieve high accuracy in multi-class tumor classification.
